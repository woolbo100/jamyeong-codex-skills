# 출고 QA

## 원고

- 제목·부제·목차·장 제목의 약속이 서로 일치한다.
- 각 장이 새 정보나 새로운 적용을 제공한다.
- 맞춤법, 조사, 띄어쓰기, 깨진 글자, 중복 문단을 점검했다.
- 번호 체계(부/장/절)가 끝까지 일관된다.
- 사실·통계·전문가 주장은 출처 또는 신중한 표현을 갖춘다.
- 체크리스트와 실천법은 독자가 실제로 수행할 수 있다.

## 이미지

- 표지, 판권, 장 이미지의 팔레트와 광원이 한 세트로 보인다.
- 표지와 장 오프너 이미지는 A4 세로 한 페이지 비율이며 Word에서 한 페이지 전체로 배치했다.
- 표지와 장 오프너 이미지 안의 제목·부제·장 번호·장 제목 텍스트가 확정 원고와 일치한다.
- 장 오프너가 가로 배너처럼 본문 중간에 들어가지 않았고, 본문은 다음 페이지부터 시작한다.
- 판권 배경 이미지와 판권 문구는 책 맨 뒤에 배치되어 있다.
- 판권 배경 이미지는 텍스트 없는 배경이며 판권 문구는 Word 텍스트로 편집 가능하다.
- 기형 손, 중복 사물, 깨진 얼굴, 워터마크, 의미 없는 문자가 없다.
- 텍스트 안전 영역이 확보되며 삽입 후 찌그러지지 않는다.
- 장 내용과 상징이 대응하며 같은 이미지를 반복 사용하지 않는다.

## 판권

- 저자, 발행처, 발행일, 연락처, ISBN은 제공된 사실만 사용한다.
- 저작권 문구, 무단 복제 금지, 이미지/폰트 라이선스 정보를 확인한다.
- 의료·심리·재무 등 필요한 면책 문구는 과도하지 않게 포함한다.

## DOCX 렌더

- 표지, 목차, 판권, 각 장이 의도한 페이지에서 시작한다.
- 외톨이 제목, 빈 페이지, 표 잘림, 이미지 겹침, 페이지 번호 오류가 없다.
- 제목 1/2/3, 본문, 인용, 실천 박스가 실제 Word 스타일로 적용된다.
- 기본 글자 크기는 본문 12pt, 큰 제목 22pt 안팎, 장 제목 18pt, 소제목 14pt로 읽기 쉽게 설정했다.
- 본문 줄간격은 1.5로 설정했다.
- Word 기본 불릿 점, 하이픈, 체크박스 기호가 좌측에 과하게 반복되지 않도록 목록을 일반 문장으로 처리했다.
- 제목 문단 앞에 점이나 불릿이 붙지 않는지 확인했다.
- 자동 목차를 Word에서 업데이트할 수 있다.
- 모든 최종 페이지 PNG를 100%로 직접 확인했다.
