# JMSCHOOL Codex Free TTS Skill

API 키 없이 `edge-tts`로 음성 MP3를 만드는 Codex 스킬입니다.

## Windows 첫 설치
1. 이 폴더를 Codex 스킬 폴더에 설치/복사합니다.
2. `install_windows.bat`를 한 번 실행합니다.
3. Codex를 다시 시작합니다.
4. 예: `이 대본을 한국어 여성 목소리 MP3로 만들어줘.`

기본 한국어 여성 음성: `ko-KR-SunHiNeural`
기본 한국어 남성 음성: `ko-KR-InJoonNeural`

주의: API 키는 필요 없지만 음성 생성 시 인터넷 연결은 필요합니다.
