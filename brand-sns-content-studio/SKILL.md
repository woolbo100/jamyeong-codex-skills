# 브랜드 SNS 콘텐츠 스튜디오

한 주제를 여러 채널에 그대로 복사하지 말고, 각 채널의 소비 방식에 맞게 다시 기획한다. 브랜드의 말투·타깃·목표를 유지하면서 바로 게시하거나 약간만 다듬어 쓸 수 있는 한국어 원고를 만든다.

## 시작하기

사용자가 준 정보부터 활용한다. 아래 항목이 없더라도 결과에 큰 영향을 주지 않으면 합리적으로 가정하고, 가정은 결과 앞에 짧게 밝힌다.

- 브랜드명과 분야
- 핵심 고객
- 브랜드 콘셉트와 말투
- 주제와 콘텐츠 목적
- 연결할 상품·서비스·무료 자료
- 원하는 채널
- 광고 강도와 콘텐츠 길이

브랜드 설정이 없으면 [브랜드 프로필](references/brand-profile.md)의 간단 양식을 먼저 제시한다. 주제만 있고 채널이 없으면 목적에 맞는 2~4개 채널을 추천한 뒤 제작한다. 사용자가 질문에 답하지 않아도 진행 가능한 경우 작업을 멈추지 않는다.

## 작업 방식

1. 주제를 고객의 문제, 욕구 또는 변화와 연결해 하나의 핵심 메시지로 정리한다.
2. 콘텐츠 목적을 인지도, 공감, 신뢰, 참여, DB 수집, 판매 중 하나의 주목적으로 정한다.
3. 모든 채널이 공유할 핵심 주장과 근거를 고정하되, 훅·전개·길이·CTA는 채널별로 바꾼다.
4. 요청된 채널에 맞춰 [채널별 규칙](references/channel-guide.md)을 읽고 원고를 제작한다.
5. 건강·금융·법률·점술 등 주의가 필요한 분야이거나 판매 문구가 포함되면 [품질과 안전](references/quality-check.md)을 적용한다.
6. 최종 결과에서 중복, 과장, 어색한 AI 문체, CTA 불일치, 채널 규격 누락을 점검한다.

## 기본 출력

여러 채널 요청 시 다음 순서로 간결하게 제공한다.

1. 콘텐츠 전략 요약: 핵심 메시지, 타깃 감정, 목적, CTA
2. 채널별 완성 원고
3. 필요한 경우 썸네일 문구, 이미지/영상 아이디어, 해시태그
4. 추천 발행 순서와 재활용 연결: 채널이 3개 이상일 때만 포함

결과는 설명보다 완성 원고가 중심이어야 한다. 사용자가 개수나 길이를 정하면 그대로 따른다. 정하지 않았으면 실제 게시에 적합한 분량으로 작성한다.

## 작성 원칙

- 첫 문장은 타깃의 상황이나 욕구를 정확히 짚는다. 무조건 자극적인 공포·비난·단정으로 시작하지 않는다.
- 브랜드 말투를 표면적인 어미가 아니라 관점, 어휘, 문장 리듬, 감정 강도까지 일관되게 반영한다.
- 채널마다 같은 문장과 제목을 반복하지 않는다.
- 독자가 얻는 정보나 변화가 먼저이고 판매 문구는 그다음이다.
- 사실처럼 보이는 통계, 후기, 성과, 긴급성, 자격, 효능을 만들어내지 않는다.
- 해시태그는 관련성 높은 것만 사용하며 과도하게 나열하지 않는다.
- 이미지 생성이 요청되지 않았다면 이미지 자체를 만들지 말고 기획이나 프롬프트만 제공한다.
- 발행·예약·외부 서비스 업로드는 사용자의 별도 요청과 권한이 있을 때만 수행한다.

## 빠른 호출 예시

```text
$brand-sns-content-studio
브랜드명: 온마음 공방
분야: 중년 여성을 위한 그림책 수업
타깃: 새로운 취미와 자기표현을 원하는 40~60대 여성
말투: 따뜻하고 쉬우며 용기를 주는 말투
주제: 그림을 못 그려도 그림책을 만들 수 있는 이유
목적: 무료 설명회 신청
채널: 네이버 블로그, 인스타그램, 스레드, 유튜브 쇼츠
광고 강도: 자연스럽게
```
