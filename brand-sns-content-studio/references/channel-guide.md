# 채널별 제작 규칙

요청된 채널 항목만 적용한다. 플랫폼 규격이 사용자의 지시와 충돌하면 사용자 지시를 우선한다.

## 네이버 블로그

- 검색 의도를 반영한 제목 3개
- 공감 또는 문제 제기 도입, 명확한 소제목, 읽기 쉬운 본문
- 핵심 키워드는 자연스럽게 사용하고 반복 삽입하지 않는다.
- 결론에서 본문과 직접 연결되는 CTA를 1개 제안한다.
- 필요 시 대표 이미지 문구 2~3개와 이미지 아이디어를 제공한다.

## 인스타그램 피드·캐러셀

- 캐러셀은 표지 1장, 핵심 전개, 요약 또는 CTA의 흐름으로 구성한다.
- 장별 문구는 모바일에서 빠르게 읽히도록 한 메시지에 집중한다.
- 캡션은 캐러셀을 그대로 반복하지 말고 맥락이나 사례를 보완한다.
- 저장·공유·댓글 요청은 내용과 자연스럽게 연결될 때만 사용한다.
- 해시태그는 핵심·세부·브랜드 태그를 섞어 5~10개 이내로 제안한다.

## 스레드

- 첫 줄만 읽어도 관점이 드러나는 훅을 쓴다.
- 짧은 문단과 대화형 리듬을 사용한다.
- 한 게시물에는 하나의 핵심 주장만 담는다.
- 요청 시 단일 글, 연속 스레드, 서로 다른 훅 버전으로 구분한다.
- 억지 질문보다 경험이나 의견을 말하기 쉬운 마무리를 사용한다.

## 유튜브 쇼츠·인스타 릴스

- 기본은 30~60초이며 사용자가 지정한 길이를 우선한다.
- 0~3초 훅, 핵심 전개, 반전·요약, CTA의 흐름으로 작성한다.
- 내레이션과 화면 자막을 구분하고 자막은 더 짧게 쓴다.
- 요청 시 장면 번호, 예상 길이, 화면/영상 프롬프트, 대사, 효과음, 전환을 표로 정리한다.
- 제목 3개와 썸네일 문구 3개를 제공한다.

## 유튜브 롱폼

- 제목 후보, 썸네일 문구, 오프닝, 본론 챕터, 마무리 CTA를 구성한다.
- 초반에 시청자가 얻게 될 결과를 알려주고 중간마다 사례·질문·전환을 배치한다.
- 말로 읽었을 때 자연스러운 문장으로 쓴다.

## 네이버 카페·밴드·커뮤니티

- 광고문보다 경험, 정보, 질문 중심으로 시작한다.
- 커뮤니티 성격에 맞춰 친밀도를 조절한다.
- 외부 링크나 판매 CTA는 본문에 충분한 가치가 있을 때 한 번만 사용한다.

## 카카오채널·문자

- 가장 중요한 혜택과 행동을 앞부분에 둔다.
- 짧고 명확하게 쓰고 링크 자리표시자를 분명히 한다.
- 허위 마감, 과도한 특수문자, 반복 발송처럼 보이는 표현을 피한다.

## 이메일 뉴스레터

- 제목 3개, 프리헤더 1개, 본문, CTA 버튼 문구를 제공한다.
- 한 이메일에는 하나의 주요 행동만 둔다.
- 개인적인 도입을 쓰더라도 독자의 문제와 자연스럽게 연결한다.
