# 채널별 제작 규칙

요청된 채널 항목만 적용한다. 플랫폼 규격이 사용자의 지시와 충돌하면 사용자 지시를 우선한다.

여러 채널을 동시에 제작할 때는 각 채널의 결과물을 독립된 섹션으로 분리한다. 같은 핵심 메시지를 쓰더라도 훅, 콘텐츠 구조, 문장 길이, 말투, 정보 밀도, CTA, 콘텐츠 형식을 채널마다 다르게 설계한다. 한 채널의 문장을 다른 채널에 줄이거나 표현만 바꿔 재사용하지 않는다.

## 네이버 블로그

- 반드시 다음 순서로 출력한다: 검색형 제목 후보 3개, 핵심 키워드, 도입부, 소제목 3~5개, 실제 게시 가능한 완성 본문, 마무리, CTA, 대표 이미지 문구 3개.
- 본문은 특별한 요청이 없으면 약 1,500~2,500자 수준으로 충분히 작성한다.
- 검색 의도를 반영한 제목 3개를 제안한다.
- 공감 또는 문제 제기 도입, 명확한 소제목, 읽기 쉬운 본문을 작성한다.
- 핵심 키워드는 자연스럽게 사용하고 반복 삽입하지 않는다.
- 결론에서 본문과 직접 연결되는 CTA를 1개 제안한다.
- 대표 이미지 문구는 3개 제공한다. 필요하면 이미지 아이디어도 덧붙인다.

## 인스타그램 피드·캐러셀

- 캐러셀 기준으로 반드시 다음 항목을 포함한다: 표지 문구, 2~7장 카드별 헤드라인, 각 카드의 짧은 본문, 마지막 CTA 카드, 별도의 인스타그램 캡션, 해시태그 5~10개.
- 캐러셀은 표지 1장, 핵심 전개, 요약 또는 CTA의 흐름으로 구성한다.
- 장별 문구는 모바일에서 빠르게 읽히도록 한 메시지에 집중한다.
- 캡션은 캐러셀을 그대로 반복하지 말고 맥락이나 사례를 보완한다.
- 카드뉴스 문구와 캡션은 같은 내용을 그대로 반복하지 않는다.
- 저장·공유·댓글 요청은 내용과 자연스럽게 연결될 때만 사용한다.
- 해시태그는 핵심·세부·브랜드 태그를 섞어 5~10개 이내로 제안한다.

## 스레드

- 기본적으로 서로 다른 스타일의 글 3개를 제안한다: A. 공감형, B. 통찰형, C. 경험형.
- 각 글은 첫 줄 훅, 짧은 문단 중심 본문, 한 게시물 하나의 주장, 자연스러운 마무리를 반드시 갖춘다.
- 첫 줄만 읽어도 관점이 드러나는 훅을 쓴다.
- 짧은 문단과 대화형 리듬을 사용한다.
- 한 게시물에는 하나의 핵심 주장만 담는다.
- 요청 시 단일 글, 연속 스레드, 서로 다른 훅 버전으로 구분한다.
- 억지 질문보다 경험이나 의견을 말하기 쉬운 마무리를 사용한다.

## 유튜브 쇼츠·인스타 릴스

- 기본은 30~60초이며 사용자가 지정한 길이를 우선한다.
- 0~3초 훅, 핵심 전개, 반전·요약, CTA의 흐름으로 작성한다.
- 내레이션과 화면 자막을 구분하고 자막은 더 짧게 쓴다.
- 반드시 장면별 표로 작성한다. 표에는 장면 번호, 시간, 화면, 내레이션, 화면 자막, 효과 또는 전환을 포함한다.
- 추가로 제목 3개, 썸네일 문구 3개, 영상 설명, CTA를 포함한다.

## 채널 간 최종 비교 점검

여러 채널을 제작한 뒤 최종 답변 전에 다음 항목을 검사한다.

- 같은 문장 복사 여부
- 같은 훅 반복 여부
- 같은 CTA 반복 여부
- 플랫폼별 형식 차이가 충분한지

유사도가 높으면 같은 핵심 메시지는 유지하되 해당 채널의 훅, 구조, 말투, 정보 밀도, CTA, 형식을 다시 작성한다.

## 유튜브 롱폼

- 제목 후보, 썸네일 문구, 오프닝, 본론 챕터, 마무리 CTA를 구성한다.
- 초반에 시청자가 얻게 될 결과를 알려주고 중간마다 사례·질문·전환을 배치한다.
- 말로 읽었을 때 자연스러운 문장으로 쓴다.

## 네이버 카페·밴드·커뮤니티

- 광고문보다 경험, 정보, 질문 중심으로 시작한다.
- 커뮤니티 성격에 맞춰 친밀도를 조절한다.
- 외부 링크나 판매 CTA는 본문에 충분한 가치가 있을 때 한 번만 사용한다.

## 카카오채널·문자

- 가장 중요한 혜택과 행동을 앞부분에 둔다.
- 짧고 명확하게 쓰고 링크 자리표시자를 분명히 한다.
- 허위 마감, 과도한 특수문자, 반복 발송처럼 보이는 표현을 피한다.

## 이메일 뉴스레터

- 제목 3개, 프리헤더 1개, 본문, CTA 버튼 문구를 제공한다.
- 한 이메일에는 하나의 주요 행동만 둔다.
- 개인적인 도입을 쓰더라도 독자의 문제와 자연스럽게 연결한다.
