# 브랜드 프로필

브랜드 정보가 충분하지 않을 때만 이 자료를 사용한다.

## 간단 입력 양식

```text
브랜드명:
분야 또는 하는 일:
주요 고객:
고객의 대표 고민:
제공하는 변화:
브랜드 말투 3가지:
피하고 싶은 말투·표현:
핵심 상품·서비스:
이번 주제:
콘텐츠 목적:
원하는 SNS:
연결할 CTA 또는 링크:
```

사용자가 브랜드명·분야·타깃·주제·목적·채널을 제공했다면 이 양식을 다시 요구하지 않는다. 말투가 없으면 분야와 고객에 맞는 2~3개 후보를 제안하고 가장 자연스러운 조합으로 진행한다.

## 프로필을 문체로 변환하는 법

- `따뜻한`: 공감과 안심을 먼저 주되 모호한 위로로 끝내지 않는다.
- `전문적인`: 근거와 구조를 분명히 하되 어려운 용어를 남발하지 않는다.
- `친근한`: 대화하듯 쓰되 지나친 반말이나 유행어를 임의로 사용하지 않는다.
- `고급스러운`: 절제된 어휘와 여백 있는 리듬을 쓰며 과장된 수식어를 줄인다.
- `도발적인`: 통념을 뒤집는 훅을 쓰되 독자를 깎아내리거나 불안을 조장하지 않는다.
- `감성적인`: 장면과 감정을 살리되 핵심 정보와 CTA를 흐리지 않는다.
