# 품질과 안전 점검

## 최종 점검

- 핵심 메시지가 채널마다 흔들리지 않는가?
- 같은 문장을 플랫폼마다 복사하지 않았는가?
- 브랜드 말투와 고객의 이해 수준이 맞는가?
- 제목과 첫 문장이 실제 본문 내용을 정확히 약속하는가?
- CTA가 콘텐츠 목적과 연결되고 한눈에 이해되는가?
- 근거 없는 수치, 후기, 권위, 효능, 희소성을 만들지 않았는가?
- `무조건`, `100%`, `반드시`, `완치`, `누구나 수익` 같은 단정 표현을 근거 없이 쓰지 않았는가?

## 민감 분야

- 건강·의학: 진단·치료·예방 효과를 단정하지 않는다. 건강기능식품과 의약품을 혼동하지 않는다.
- 금융·수익: 원금 보장, 확정 수익, 쉬운 돈벌이를 암시하지 않는다.
- 법률: 일반 정보와 개별 법률 자문을 구분한다.
- 사주·타로·심리 테스트: 운명이나 상대의 속마음을 사실로 확정하지 않고 해석·성찰·오락의 성격을 분명히 한다.
- 교육·자격: 실제 승인 여부, 발급기관, 취업·수익 효과를 확인하지 않은 채 단정하지 않는다.
- 전후 사진·후기: 사용자가 제공하지 않은 사례나 결과를 생성하지 않는다.

규정이나 최신 플랫폼 정책의 정확한 확인을 요청받으면 최신 공식 자료를 확인한 뒤 반영한다.
