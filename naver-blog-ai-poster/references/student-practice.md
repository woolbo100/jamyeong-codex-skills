# 실습 예시

## 1. 정보형 포스팅

사용자:
> 초보자를 위한 캔바 AI 활용법으로 네이버 블로그 글을 써서 임시저장해줘.
> 대상은 40~60대 강사들이고 너무 어려운 용어는 빼줘.

기대 동작:
1. 독자와 검색 의도 파악
2. 제목 후보 생성 후 하나 선택
3. 모바일 가독성 중심 글 작성
4. 네이버 로그인 상태 확인
5. 글쓰기 화면 진입
6. 제목/본문 입력
7. 태그 입력
8. 내용 검수
9. 임시저장

## 2. 홍보형 포스팅

사용자:
> AI 그림책 6주 과정 모집글을 써줘.
> 대상은 AI를 처음 배우는 강사와 1인 창업자야.
> 수업 장점은 실시간 실습, 결과물 완성, 피드백이고
> 신청 링크는 https://example.com/apply 이야.
> 네이버 블로그에는 임시저장까지만 해줘.

주의:
- 제공되지 않은 모집 인원, 할인율, 매출 성과, 후기를 만들어내지 않는다.
- 신청 URL을 임의 변경하지 않는다.

## 3. 최종 발행

사용자:
> 아까 임시저장한 글 확인했어. 그대로 공개 발행해줘.

기대 동작:
- 현재 편집 글이 맞는지 제목으로 확인
- 발행 설정 snapshot
- 공개 범위 및 카테고리 확인
- 최종 발행
- 가능하면 게시 URL 보고
