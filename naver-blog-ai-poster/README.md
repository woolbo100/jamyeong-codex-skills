# 네이버 블로그 AI 포스팅 자동화 스킬

수강생용 범용 Codex 스킬입니다.

## 할 수 있는 것

- 주제/키워드 기반 네이버 블로그 글 작성
- 제목, 소제목, CTA, 해시태그 구성
- 로그인된 브라우저에서 네이버 블로그 글쓰기 화면 진입
- 제목/본문 입력
- 가능한 경우 이미지 삽입
- 태그/카테고리 설정
- 기본: 임시저장
- 명시적 요청 시: 발행 또는 예약발행

## 권장 설치 위치

프로젝트 전용으로 쓸 때는 프로젝트 내부의 Codex 스킬 폴더에 넣고 사용하세요.
Codex 환경별 스킬 경로가 다를 수 있으므로 현재 Codex가 사용하는 Skills 경로 아래에
`naver-blog-ai-poster` 폴더 전체를 복사하는 방식이 가장 안전합니다.

핵심 파일은 `SKILL.md` 입니다.

## 중요한 보안 원칙

네이버 ID/비밀번호를 SKILL.md, .env, 예제 파일에 직접 적지 마세요.
브라우저 로그인 세션을 재사용하는 방식을 권장합니다.
인증 세션 파일은 GitHub에 올리지 마세요.

## 수업에서 추천하는 진행 방식

1. 수강생이 네이버에 직접 로그인
2. Codex에게 글 주제 전달
3. Codex가 글 생성
4. 네이버 편집기에 자동 입력
5. 임시저장
6. 수강생이 최종 확인
7. 필요할 때만 직접 발행 또는 Codex에 발행 요청

처음 실습에서는 `임시저장`까지만 자동화하는 것을 권장합니다.

## 예시 명령

`30~50대 초보자를 대상으로 캔바 AI 기능 소개글을 1,500자 정도로 작성해서 내 네이버 블로그에 임시저장해줘.`

`이 원고는 내용 수정 없이 네이버 블로그에 넣고, 제목은 "AI로 전자책 표지 만들기"로 해서 임시저장해줘.`

## 백도화 전용 버전

백도화처럼 브랜드 톤이 강한 프로젝트는 이 범용 스킬을 그대로 수정하기보다 복사본을 만들어
브랜드 전용 문체/CTA/상품/카테고리/이미지 규칙을 추가하는 것을 추천합니다.
