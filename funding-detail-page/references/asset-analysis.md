# Asset Analysis

Use this reference when the user provides creator, offer, proof, or product assets.

## Analyze

Identify:

- asset type: creator photo, product mockup, curriculum screenshot, review, sales/funding proof, logo, community screenshot, policy, FAQ, other
- credibility level: usable as proof, design reference only, verification needed, risky/unusable
- visible text and whether it is readable enough for final production
- crop opportunities and text-safe spaces
- emotional role: trust, proof, story, reward clarity, urgency, FAQ, brand atmosphere
- quality issues: blur, low resolution, clutter, private information, cropped context, unreadable numbers, inconsistent branding

## Placement

Recommend where each asset belongs:

- hero: strongest creator/product/offer identity visual
- proof: reviews, screenshots, funding results, social proof
- founder story: creator photo, behind-the-scenes, origin story
- method/curriculum: diagrams, module screenshots, roadmap
- reward: mockups, bundle visuals, tier comparison
- FAQ/policy: clean information blocks, not emotional hero visuals

## Safety

Never turn a screenshot into a stronger claim than it supports. If a number, review, or ranking is cropped or unverifiable, mark it as `검증 필요`. Hide or avoid personal information unless the user explicitly asks and has permission.
