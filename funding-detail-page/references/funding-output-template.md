# Funding Output Template

Use this format for each cut in the planning output.

```text
### 컷 N. [컷 제목]

- 목적:
- 후원자 심리:
- 헤드라인:
- 서브카피:
- 이미지 내 삽입 문구:
- 이미지 구성:
- 자료 배치 추천:
- 자료 품질 판단:
- ASCII 레이아웃:
  [모바일 세로형 와이어프레임]
- 사실 정보:
- 사용 자료:
- 디자인 메모:
- 최종 이미지 QA:
- 확인 필요:
```

## Copy Rules

- Headlines should be short enough for mobile, usually 1 to 2 lines.
- Use direct Korean sales copy, not academic explanation.
- Make benefits concrete, but do not invent outcomes.
- Replace unsupported proof with `확인 필요`.
- Avoid filler phrases such as `놀라운`, `완벽한`, `압도적`, unless supported by clear evidence.

## ASCII Rules

Show only layout structure:

```text
+----------------------+
| HEADLINE             |
| subcopy              |
| [creator/product]    |
| [proof/reward block] |
| CTA                  |
+----------------------+
```

Do not include image-generation prompts in planning output.
