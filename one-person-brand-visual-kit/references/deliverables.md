# 결과물 규격

## 1차 결과물

### 1. 브랜드 전략 요약서

- 브랜드 한 줄 정의
- 핵심 고객과 핵심 문제
- 고객에게 약속하는 변화
- 차별점 3개 이내
- 핵심 가치 3개
- 브랜드 성격 3~5개
- 브랜드 세계관: 출발점, 여정, 도착점
- 브랜드 핵심 메시지
- 슬로건 3안과 최종 추천
- 권장 말투와 피해야 할 표현

### 2. 컬러·폰트·이미지 스타일 보드

- 메인, 서브, 포인트, 배경, 텍스트 컬러의 HEX와 역할
- 제목, 소제목, 본문, 포인트용 폰트 역할과 후보
- 사진의 피사체, 구도, 조명, 색보정, 질감
- 일러스트·아이콘·패턴 방향
- 사용해야 할 요소와 피해야 할 요소
- 이미지 생성용 공통 마스터 프롬프트
- 캔바 검색 키워드 8~12개

### 3. 로고 콘셉트 3안

각 안에 다음을 포함한다.

- 콘셉트명과 한 문장 설명
- 로고 유형과 형태
- 상징의 의미
- 권장 서체와 글자 배치
- 컬러 적용
- 적합한 사용처
- 장점과 주의점
- 흰 배경·어두운 배경·단색 적용 방향
- 시안 생성 프롬프트

세 안은 색만 바꾼 변형이 아니라 상징과 조형 논리가 달라야 한다.

사용자가 1안을 확정하면 해당 안을 다음의 최종 로고 파일로 완성한다. 이 파일들은 별도 결과물로 세지 않고 3번 결과물에 포함한다.

- 기본형 가로 로고
- 세로 또는 스택형 로고
- 심볼·파비콘용 축약 로고
- 밝은 배경용, 어두운 배경용, 단색 버전
- 투명 배경 PNG와 편집 가능한 SVG
- 최소 사용 크기, 보호 여백, 금지 변형 안내
- 생성형 이미지의 글자 오류를 그대로 납품하지 말고 정확한 텍스트·벡터로 재구성

## 2차 결과물

### 4. 명함 앞·뒷면

- 기본 크기: 90×50mm, 인쇄소 규격이 있으면 우선
- 앞면: 로고, 브랜드명, 슬로건 중심
- 뒷면: 이름, 직함, 연락처, 채널, QR 자리
- 재단 여백과 안전 여백 안내
- 앞·뒷면별 텍스트, 정렬, 크기 위계, 색상, 이미지 요소

### 5. SNS 프로필과 채널별 배너

사용 채널만 제작한다. 채널 규격은 변할 수 있으므로 실제 제작 시 최신 권장 크기를 확인하거나 사용자가 제공한 규격을 따른다.

- 프로필: 작은 원형 크롭에서도 인식되는 심볼 또는 축약 로고
- 배너: 브랜드명, 핵심 혜택, 슬로건, CTA의 위계
- 모바일·데스크톱 안전 영역 고려
- 채널별 문구, 레이아웃, 이미지 프롬프트

### 6. 홍보 포스터

- 기본 방향: 온라인 세로형 1080×1350px. 다른 용도가 있으면 변경
- 제목, 고객 문제, 핵심 혜택, 구성, 신뢰 요소, CTA, QR/연락처 자리
- 한 화면에서 메시지 하나만 강조
- 실제 가격·날짜·장소가 없으면 `[입력 필요]` 처리

### 7. 카드뉴스 5장 예시

기본 구조:

1. 표지: 타깃을 멈추게 하는 한 문장
2. 공감: 고객이 겪는 문제
3. 통찰: 문제를 새롭게 이해시키는 관점
4. 해결: 상품·서비스 또는 실천 방법
5. CTA: 신청·문의·저장·팔로우 중 하나

각 장마다 다음을 제공한다.

- 핵심 문구와 보조 문구
- 레이아웃과 시선 흐름
- 배경·이미지·도형 지침
- 이미지 생성 프롬프트 또는 캔바 검색어
- 접근성을 고려한 대비와 글자 크기 위계

### 8. 홍보용 브랜드 모션그래픽

- 결과 파일: 8초 MP4, H.264, yuv420p, 1920×1080, 30fps
- 0–2초: 브랜드 컬러와 상징 패턴 등장
- 2–5초: 확정 심볼·로고가 부드럽게 나타나며 완성
- 5–7초: 브랜드명과 슬로건 등장
- 7–8초: 완성 로고 고정 후 마무리
- 로고와 글자는 생성형 영상에 맡기지 않고 확정 PNG/SVG와 실제 텍스트를 합성
- 과도한 효과보다 Brand DNA와 가독성을 우선
- 오디오는 기본 무음으로 제작하고, 사용자가 제공하거나 사용 허가가 확인된 사운드만 추가

실제 렌더링 명령 예시:

```bash
python3 scripts/render_brand_intro.py \
  --logo /absolute/path/logo.png \
  --brand-name "브랜드 이름" \
  --slogan "브랜드 슬로건" \
  --primary "#2E1A47" \
  --secondary "#C9A86A" \
  --font /absolute/path/korean-font.ttf \
  --output /absolute/path/brand-intro.mp4
```

완료 후 다음을 검증한다.

- 영상 길이 8초
- 1920×1080, 30fps
- H.264와 yuv420p
- 로고 비율과 투명 배경 정상
- 한글 깨짐과 잘림 없음
- 시작·중간·마지막 대표 프레임의 일관성

## 캔바 구현용 출력 형식

각 시안은 아래 필드로 정리한다.

| 필드 | 내용 |
|---|---|
| Canvas | 크기와 방향 |
| Copy | 그대로 붙여넣을 문구 |
| Layout | 위치, 정렬, 여백, 위계 |
| Style | 색상 코드, 폰트 역할, 효과 |
| Visual | 사진·일러스트·패턴 지침 |
| Prompt | 이미지 생성 프롬프트 |
| Replace | 사용자가 교체할 정보 |

## 최종 일관성 검사

- [ ] 8종 결과물이 하나의 브랜드로 인식된다.
- [ ] 선택한 로고 콘셉트 외의 상징이 섞이지 않았다.
- [ ] 색상 코드와 폰트 역할이 Style Board와 일치한다.
- [ ] 브랜드 말투와 핵심 메시지가 일치한다.
- [ ] 로고 주변 여백과 최소 크기를 해치지 않는다.
- [ ] 작은 화면에서도 주요 문구가 읽힌다.
- [ ] 배경과 텍스트의 대비가 충분하다.
- [ ] 이미지의 조명, 색감, 인물·사물 표현이 통일되어 있다.
- [ ] 날짜, 가격, 연락처 등 미확정 정보가 명확히 표시되었다.
- [ ] 각 자산의 CTA가 사용 목적에 맞다.
- [ ] 인트로 MP4가 정확히 8초이며 로고·글자가 변형되지 않았다.
