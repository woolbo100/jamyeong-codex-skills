# Motion Graphic Studio

사용자가 모션그래픽 영상 콘셉트, 장면 구성, 카피, 디자인 방향, Remotion 구현, 렌더 가능한 프로젝트를 원할 때 사용한다.

목표는 짧은 요청만으로도 고급스럽고 읽기 쉬우며 초보자도 수정하기 쉬운 모션그래픽 패키지를 만드는 것이다.

## 기본 판단

사용자가 세부 정보를 주지 않으면 아래 기본값으로 판단하고 진행한다.

- 플랫폼: 세로형 SNS 영상
- 화면 비율: `9:16`
- 길이: `15s`
- FPS: `30`
- 분위기: 고급스럽고 차분한 미니멀 브랜드 톤
- CTA: 문맥에 맞게 `자세히 보기`, `지금 신청하기`, `문의하기`, `홈페이지 바로가기` 중 선택
- 시각 자료: 로고나 이미지가 없으면 텍스트 로고와 타이포그래피 중심 추상 배경 사용

정확한 브랜드명, 필수 고지 문구, 반드시 써야 하는 에셋처럼 결과를 크게 바꾸는 정보가 없을 때만 짧게 질문한다.

## 작업 방식

기획만 요청받은 경우 다음을 제공한다.

1. 프로젝트 요약
2. 콘셉트
3. 장면 구성표
4. 카피 문안
5. 디자인 및 모션 방향
6. 수정 포인트

구현을 요청받은 경우 렌더 가능한 Remotion 프로젝트를 만들거나 수정하고 다음을 포함한다.

1. 수정 가능한 콘텐츠 데이터
2. 공통 디자인 토큰
3. 재사용 가능한 모션 헬퍼
4. 장면 컴포넌트
5. 메인 컴포지션
6. 실행 또는 공유에 필요한 README나 사용 안내
7. 렌더 명령과 결과물 경로

사용자가 영상을 만들어 달라거나, 생성, 구현, 렌더링을 요청하면 단편 코드보다 완성된 프로젝트를 우선한다.

## 결과물 기준

모든 모션그래픽은 아래 기준을 통과해야 한다.

- 첫 1-2초에 시선을 끌되 과하지 않다.
- 텍스트는 영상 속도에서 읽을 수 있을 만큼 짧다.
- 타이포그래피 위계가 분명하다.
- 선택한 플랫폼의 안전 영역을 고려한다.
- 모션은 내용을 방해하지 않고 이해를 돕는다.
- 장면 수가 영상 길이에 맞다.
- 마지막 CTA 또는 브랜드 락업이 안정적으로 보인다.
- 콘텐츠, 색상, 타이밍, 카피를 쉽게 수정할 수 있다.

## 참고 문서 선택

현재 요청에 필요한 참고 문서만 읽는다.

- 미감, 레이아웃, 카피 톤, 브랜드 모드, 품질 점검이 필요하면 [references/design-direction.md](references/design-direction.md)를 읽는다.
- Remotion 파일 구조, 타이밍, 구현, 렌더링 규칙이 필요하면 [references/remotion-build.md](references/remotion-build.md)를 읽는다.

사용자가 특정 브랜드, 타깃, 플랫폼, 형식을 지정하면 기본값을 고집하지 말고 그 맥락에 맞춘다.
